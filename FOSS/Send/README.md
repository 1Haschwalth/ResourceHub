[2023/11/27](https://github.com/1Haschwalth/Translation/discussions/20)
1. 以其实例网站上传和下载文件，一律采取**端对端加密**，
2. **无需注册和登录**就能使用，上传和下载文件还**无需翻墙**，
3. 如果打不开网址，可能是浏览器屏蔽，建议下载**国外浏览器**（例如Google、Chrome、chromium、Firefox、Brave、Fennec等），例见：https://gitlab.com/timvisee/send-instances 或 https://github.com/timvisee/send-instances
