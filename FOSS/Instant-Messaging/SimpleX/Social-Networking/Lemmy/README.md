# [Lemmy](https://github.com/LemmyNet)
>**https://join-lemmy.org/docs/introduction.html**

### [1. 介绍](https://join-lemmy.org/docs/introduction.html#introduction)
Lemmy 是一个自托管的联合社交链接聚合和讨论论坛。它由许多专注于不同主题的社区组成。用户可以发布文字、链接或图片，并与他人进行讨论。投票有助于将最有趣的项目置顶。有强大的管理工具来防止垃圾邮件和巨魔。所有这些都是完全免费和开放的，不受任何公司控制。这意味着没有广告、跟踪或秘密算法。

联盟是一种去中心化的形式。每个人都可以使用多种服务，而不是单一的中央服务。

Lemmy 网站可以单独运行。就像传统网站一样，人们可以在上面注册、发布信息、上传图片和相互交流。与传统网站不同的是，Lemmy 实例可以互操作，让用户相互交流；就像你可以从 Gmail 账户向 Outlook、Fastmail、Proton Mail 或其他任何电子邮件提供商的用户发送电子邮件一样，只要你知道他们的电子邮件地址，你就可以在任何网站上使用他们的地址提及任何人或给任何人发消息。

Lemmy 使用一种标准化的开放协议来实现联合，这种协议被称为 ActivityPub。任何通过 ActivityPub 实现联盟的软件都可以与 Lemmy 进行无缝通信，就像 Lemmy 实例之间相互通信一样。

fediverse （"联合宇宙"）是所有可以通过 ActivityPub 和万维网相互通信的实例的名称。这包括所有 Lemmy 服务器，也包括其他实现：
- [Mastodon](https://joinmastodon.org/) (microblogging)
- [PeerTube](https://joinpeertube.org/) (videos)
- [Friendica](https://friendi.ca/) (multi-purpose)
- 以及许多更多！

在实际应用中：想象一下，如果你可以通过 Reddit 账户关注一个 Facebook 群组，并在不离开账户的情况下对其帖子发表评论。如果 Facebook 和 Reddit 是使用相同协议的联合服务，这将成为可能。有了 Lemmy 账户，你就可以与任何其他兼容实例进行通信，即使它不是在 Lemmy 上运行。只需软件支持相同的 ActivityPub 协议子集即可。

与专有服务不同，任何人都可以完全自由地运行、检查、检验、复制、修改、分发和重复使用 Lemmy 源代码。就像 Lemmy 用户可以选择服务提供商一样，作为个人，你也可以自由地为 Lemmy 贡献功能，或发布包含不同功能的 Lemmy 修改版。这些修改版（也称为软件分叉）必须与原版 Lemmy 项目保持相同的自由度。因为 Lemmy 是自由软件，尊重你的自由，所以个性化不仅是允许的，而且是鼓励的。

你可以在[git 存储库](https://github.com/LemmyNet/lemmy-docs)中为本文档做出贡献。
