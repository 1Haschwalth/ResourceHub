# Jitsi Meet音视频会议实例
这是免费自由去中心化的音视频会议实例，支持多人语音/视频会议，支持设置会议端到端加密，支持设置会议加入密码，使用无需注册账号，可在网页端直接使用，推荐搭配自由免费的浏览器使用，请勿与不可信任的人进行语音/视频会议，防止被采集声纹和ip地址信息。以下是实例链接网站：
| URL | 注册账号 | 端到端加密 | 加入密码 | 翻墙要求 |
|-|-|-|-|-|
| https://kmeet.infomaniak.com | 无需 | 支持 | 支持 | 无需 |
| https://jitsi.member.fsf.org/ | 无需 | 不支持 | 支持 | 无需 |
| https://jitsi.riot.im/ | 无需 | 不支持 | 支持 | 无需 |
| https://meet.mayfirst.org/ | 需要 | 可能支持 | 支持 | 无需 |
| https://jitsi.debian.social/ | 需要 | 可能支持 | 支持 | 无需 |
| https://jitsi.vern.cc/ | 无需 | 不支持 | 支持 | 无需 |
| https://meet.jit.si/ | 需要 | 支持 | 支持 | 无需 |
